# Prompts

Standalone system prompts you can paste into any AI tool's "custom instructions" or "system prompt" field. Use them in ChatGPT, Claude.ai Projects, Cursor, or anywhere else you can set persistent context for a model.

## How to use

1. Pick the prompt matching your task (see list below)
2. Open the corresponding `.md` file
3. Copy everything below the `---` divider
4. Paste it as your system prompt / custom instructions in your AI tool of choice
5. Start working

## Available prompts

| Prompt | Use when |
|---|---|
| `deck-architect.md` | Designing pitch decks, all-hands, customer-facing decks |
| `html-designer.md` | Building landing pages, microsites, hero sections in HTML/Tailwind |
| `brand-critic.md` | Reviewing visual work against brand consistency principles |
| `visual-reviewer.md` | Catching AI-slop patterns, spacing issues, hierarchy problems |
| `video-composer.md` | Designing video compositions, transitions, captions, motion |
| `design-system-thinker.md` | Building or evaluating design systems, color/type/spacing decisions |

## Adapting prompts

Each prompt is intentionally generic — no client names, no project specifics. Add your own context at the bottom (e.g., "Our brand uses blues and a serif headline font; we're pitching to financial services buyers.").
